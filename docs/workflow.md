# Workflow

**Reserved — Phase 2.**

This will document the workflow the agent follows, one section per step:

Orient → Plan → Act → Verify → Recover → Finish

For each step, eventually record: what the step is responsible for, what
information it needs, what it produces, and which tools it requires.

Intentionally unwritten. The workflow should be derived from watching the agent
actually work in Phases 0–1, not guessed at beforehand.
